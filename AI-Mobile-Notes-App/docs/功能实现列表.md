## 一、移动端前端（Android）

### 1. 基础架构

| 编号 | 功能 | 实现要点 |
|------|------|----------|
| F-M1 | 项目初始化 | Android Studio + Gradle + Kotlin，minSdk 24，targetSdk 34 |
| F-M2 | MVVM 架构搭建 | ViewModel + LiveData + Repository，Jetpack 组件化 |
| F-M3 | 本地数据库 | Room 持久化笔记元数据（标题、分类、时间戳、标签） |
| F-M4 | 网络层 | Retrofit2 + OkHttp，统一拦截器、Token 管理 |
| F-M5 | 图片加载 | Glide/Coil 实现图片压缩、缓存、缩放预览 |
| F-M6 | 权限管理 | Camera、Storage 运行时权限申请 |
| F-M7 | 文件存储 | 本地保存图片/导出的笔记 PDF/Markdown 文件 |

### 2. 笔记页面模块

| 编号 | 功能 | 实现要点 |
|------|------|----------|
| F-B1 | Web 框架 | FastAPI（异步、自动生成 Swagger 文档） |

| F-AI7 | 中英互译 | 翻译接口，保留术语一致性 |
| F-AI8 | 思维导图 | 输出 Markdown / JSON 树形结构 |
| F-AI9 | 自然语言检索 | 向量召回 + 关键词匹配混合检索 |

### 5. 异步与队列

| 编号 | 功能 | 实现要点 |
|------|------|----------|
| F-Q1 | 异步任务 | Celery + Redis 处理图片 OCR、摘要等耗时任务 |
| F-Q2 | 任务进度查询 | 客户端轮询任务状态：pending/running/done/failed |

## 四、端到端关键流程

### 流程 1：拍照 → 解析 → 笔记入库
```
拍照/选图 → 图片压缩 → 上传 /api/image/upload 
  → 异步任务：OCR + 知识点 + 摘要 + 题库
  → 客户端轮询 /api/task/{id} 获取结果
  → 用户确认后写入笔记，关联图片与 AI 内容
```

### 流程 2：纯文本 → 润色/翻译
```
编辑笔记 → 选中文本 → 选择"AI 润色/翻译"
  → POST /api/text/polish 或 /api/text/translate
  → 流式返回结果 → 一键替换/插入
```

### 流程 3：自然语言检索
```
搜索框输入"上周英语错题"
  → POST /api/search/semantic
  → 后端向量化 + 时间过滤 → 返回笔记列表
```
