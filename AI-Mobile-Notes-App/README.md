# 项目四：AI 随身图文笔记助手（大模型方向）

## 1. 项目简介

面向学生、职场人群的 Android 智能笔记 APP，支持拍照上传试卷、手写笔记、文档、截图，后端通过多模态大模型解析图片内文字、提取知识点、自动总结摘要、生成问答题库，同时支持文字笔记 AI 润色、翻译、思维导图生成，实现图文一体化智能笔记管理。

## 2. 三人分工

- **移动端前端（1 人）**：Android 笔记页面搭建、相机拍照 / 相册导入图片、图文笔记编辑、笔记分类文件夹、图片缩放预览、笔记搜索、本地笔记文件存储。
- **后端（1 人）**：接收图片与文本笔记、调用大模型多模态接口、提取图文信息、存储用户笔记数据、返回摘要 / 题库 / 翻译结果、分页查询笔记接口。
- **AI 模型（1 人）**：大模型 OCR 图文识别、知识点提取、内容摘要生成、题目自动出题、文本润色、中英互译、思维导图文本结构输出。

## 3. 目录结构

```
AI-Mobile-Notes-App/
├── frontend/        # Android 客户端代码
├── backend/         # Python Flask/FastAPI 后端
├── model/           # 大模型调用与 Prompt 工程
├── docs/            # 接口文档与项目说明
└── README.md
```

## 4. 技术选型

- **移动端**：Android + Room 本地数据库存储
- **后端**：Python Flask/FastAPI（轻量接口架构）
- **AI 模型**：接入多模态大模型 API（GPT-4V / 豆包 / 千问 / 文心一言等）
